## About

This project focuses on Java project design, including inheritance, polymorphism, abstract classes, interfaces, design patterns, and test-driven development. The goal of this project is to create a data management system that can store and create custom data objects that can be manipulated by the user.

### Prerequisites

Students should be able to use variables and collections, manage user input, write functions, use control flow, create classes and objects, handle exceptions, debug, exhibit inheritance and polymorphism using interfaces and abstract classes, use design patterns, and develop via test-driven development in Java.
